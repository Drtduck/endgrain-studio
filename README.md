# Endgrain Studio

Генератор узоров для торцевых разделочных досок. Проект для Вайбатона №1 (срок - 7 дней, старт 10 августа 2026).

Цель - не рисовалка, а рабочий инструмент столяра: придумать узор, увидеть готовую доску, понять схему распила и переклеек, посчитать размеры деталей, материал и отходы, сохранить проект и распечатать инструкцию для мастерской.

## Минимально рабочая версия

- редактор узора;
- несколько пород или цветов древесины;
- поворот и отражение элементов;
- настройка размеров доски;
- сохранение проекта;
- экспорт изображения узора (готово).

## Что добавляет очков

Генеративные и случайные узоры, библиотека шаблонов, интерактивное 3D-превью, учёт толщины пропила, карта раскроя в CSV, пошаговая схема переклеек в PDF, расчёт древесины и отходов, расчёт себестоимости, миллиметры и дюймы, PDF-инструкция с кириллическим шрифтом, проверка физической реализуемости, оптимизация раскроя, импорт изображения и превращение его в узор, мм и дюймы в экспорте.

## Критерии оценки

Функциональность (можно ли изготовить настоящую доску), удобство для человека, который не писал код, качество и разнообразие генерации, техническая реализация, общий вайб. Работающий продукт важнее списка функций в README.

## Что сдаём

Ссылку на работающий продукт, ссылку на репозиторий, короткое видео или GIF с демонстрацией, несколько примеров досок и краткое объяснение, как изготовить доску по полученному проекту.

## Переменные окружения

Аккаунт и облачные проекты необязательны: без переменных Supabase студия работает как раньше, локально, без кнопки аккаунта и вкладки «Мои проекты».

| Переменная | Назначение |
| --- | --- |
| `NEXT_PUBLIC_SUPABASE_URL` | URL проекта Supabase. Обязательна для аккаунта и облачных проектов, инлайнится в клиентский бандл. |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Anon-ключ Supabase. Обязателен вместе с `NEXT_PUBLIC_SUPABASE_URL`, все операции идут под ним через RLS. |
| `SUPABASE_SERVICE_ROLE_KEY` | В приложении не используется вообще. Нужен только для ручного разбора обращений в консоли Supabase. |
| `E2E_AUTH` | Флаг `1` включает `e2e/auth.spec.ts` локально. По умолчанию (без флага) и в CI спека пропускается. |
| `E2E_AUTH_EMAIL` | Email существующего тестового пользователя для второго сценария `e2e/auth.spec.ts` (только с `E2E_AUTH=1`). |
| `E2E_AUTH_PASSWORD` | Пароль того же тестового пользователя. |

Значения переменных нигде не коммитятся, `.env.local` в `.gitignore`.
