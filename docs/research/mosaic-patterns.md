# Ресерч: непрямоугольные узоры end grain досок (техдолг п.4)

Дата: 13 августа 2026. Ресерч методологии, код не пишем без него.

## 1. Столярные техники

**Chevron (шеврон):** страйп-блэнк из чередующихся пород -> рез пилой под углом 25-35° поперёк -> каждая вторая полоса переворачивается (флип) -> переклейка. Непрерывная V-линия. Туториалы: obsessedwoodworking.com (3D chevron, 35°), ashleygrenon.com, diyhuntress.com, instructables.com. Отличие от herringbone: herringbone - прямоугольные плашки зигзагом без угловых резов, chevron - угловой рез с непрерывной линией стыка.

**Tumbling blocks (3D-куб):** математическая основа rhombille tiling - ромбы 60°/120° трёх оттенков. Полосы контрастных пород -> рез под 60° -> три ориентации при переклейке. Источники: newtonmakes.com/blog/3d-cutting-board, instructables.com/3D-End-Grain-Cutting-Board-1, en.wikipedia.org/wiki/Rhombille_tiling.

**Diamond (ромбы):** полосы -> поперечные срезы под углом (не 90°) дают параллелограммы -> чередование ориентации при переклейке. Источники: lumberjocks.com (stacked diamond), rockler.com.

**Сегментные кольца (sunburst):** угол клина = 360°/(2 x сегментов). Это segmented turning, НЕ strip-техника - радиальные клинья, не прямые резы через блэнк.

## 3. Академия: guillotine-разложимость

- Guillotine partition: рекурсивные сквозные резы край-в-край (en.wikipedia.org/wiki/Guillotine_partition). Число разбиений - числа Шрёдера.
- m-guillotine partition: минимум m последовательных резов, DP за O(n^(10m+6)).
- Критерий узора: смежные элементы должны выравниваться вдоль одной прямой линии реза через весь текущий блэнк на каждом шаге. Иначе не разложимо.
- Формального алгоритма проверки для произвольных углов в литературе нет (guillotine-теория работает с прямыми углами) - открытый практический вопрос.

## 4. Вывод для Endgrain Studio

**Реализуемо через «склейка полос -> рез под углом -> переклейка» (m-guillotine, m=2-3):**
- Chevron: полосы -> угловой рез 25-45° -> флип чередующихся -> переклейка.
- Diamond: другой угол и схема чередования (по/против часовой).
- Tumbling blocks: рез 60°, три ориентации, три оттенка.

Все три - семейство периодических замощений ромбами/параллелограммами, guillotine-разложимость доказана самой столярной практикой. Общая параметрическая модель: «список полос -> угол реза -> правило чередования ориентации при переклейке».

**Не реализуемо strip-техникой (для MVP исключить или пометить «ручная доработка»):**
- Сегментные кольца/sunburst (радиальные клинья, segmented turning).
- Апериодические мозаики Penrose-типа (каждая плитка выпиливается индивидуально - маркетри).
- Криволинейные узоры (CNC-инкрустация).
- Любой узор, где граница смежных кусков - не прямая через весь блэнк.

Рекомендация: расширить движок типом узора «angled» с параметрами {angle, flipRule (chevron|diamond|tumbling)}, схема распила получает второй проход резов под углом. Формы досок (скруглённые углы, силуэты) - отдельная задача обрезки финальной доски, не влияет на распил узора (обрезка после переклейки), реализуемо как контур поверх прямоугольной заготовки с расчётом отходов.
