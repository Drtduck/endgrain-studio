# Как собрать доску по проекту из Endgrain Studio

Студия: https://endgrain-studio.vercel.app
Лендинг с описанием проекта: https://endgrain-studio.vercel.app/landing

## 1. Собрать проект в студии

Открываем студию и собираем узор одним из четырёх способов:

- вкладка «Шаблоны» - готовые узоры (шахматка, кирпич, полосы, инкрустация), сразу с числом склеек и габаритом;
- вкладка «Генератор» - девять случайных вариантов на выбор, можно перемешать, отметить понравившиеся звёздочкой и прогнать «раунд эволюции», чтобы студия смешала фаворитов с новыми узорами;
- вкладка «Фото» - загружаем картинку, студия раскладывает её на реальные породы дерева и число щитов;
- вкладка «Редактор» - ручная покраска отдельных ячеек породой дерева из палитры (любая правка создаёт форк проекта, чтобы прошлую версию всегда можно было вернуть через отмену).

Толщина доски и единицы измерения (мм или дюймы) настраиваются в редакторе, счётчик «Габарит» сразу показывает итоговый размер и число склеек. Во вкладке «3D» можно повернуть готовую доску и посмотреть на неё со всех сторон перед печатью.

## 2. Скачать PDF-инструкцию

Кнопка экспорта в PDF (вкладка «Редактор», блок экспорта) отдаёт три страницы:

1. превью доски и параметры проекта - габарит, толщина, число щитов и склеек, список пород;
2. карта раскроя щитов - какой щит из какого ряда и какой породы;
3. пошаговая схема переклейки рядов с указанием переворота (flip) и зеркалирования (mirror) там, где это нужно для рисунка.

Помимо PDF доступны SVG (для точного чертежа), PNG (для референса) и CSV (таблица склеек для раскроя на станке или ЧПУ).

## 3. В мастерской

По распечатанной инструкции:

1. **Роспуск полос.** Распускаем доски нужных пород на полосы по ширине ячеек из карты раскроя.
2. **Склейка щитов.** Полосы одного ряда склеиваются в щит в порядке, указанном в PDF, с учётом flip и mirror для симметричных узоров.
3. **Строгание.** Даём клею схватиться, затем строгаем щиты до одной толщины.
4. **Торцовка.** Торцуем щиты на нужную длину с учётом пропила 3 мм на рез и припуска 3 мм на сторону под последующую подгонку - иначе итоговый размер уйдёт от расчёта в PDF.
5. **Раскладка рядов по номерам.** Раскладываем нарезанные щиты в порядке номеров рядов из карты раскроя, сверяем с превью на первой странице PDF.
6. **Финальная склейка.** Склеиваем ряды в цельную доску по разметке.
7. **Шлифовка и масло.** Шлифуем по нарастающей зернистости и покрываем маслом для дерева.

Итог сверяем с превью и 3D-видом из студии - узор и породы должны совпасть один в один.
