# Проверка ASIN партнёрских блоков Amazon

`lib/affiliate/products.json` и `lib/affiliate/books.json` содержат позиции с
`"unverified": true`. Это означает, что ASIN подобран по памяти/поиску и не
проверен вручную. Пока флаг стоит, ссылка на позицию ведёт не на
`/dp/<ASIN>`, а на поиск Amazon по бренду и названию (`amazonSearchUrl` в
`lib/affiliate/index.ts`), чтобы битый ASIN не давал 404.

Процедура для владельца перед продом, по каждой позиции обоих файлов:

1. Открыть `https://www.amazon.com/dp/<ASIN>`.
2. Если открылась карточка того самого товара и цена попадает в заявленный
   диапазон (`band`), снять `"unverified": true` у этой позиции.
3. Если 404 или открылся другой товар, найти правильный ASIN в адресной
   строке нужной карточки на Amazon и заменить значение `asin` в JSON.
4. Если товара нет в наличии совсем, удалить позицию из JSON целиком:
   пустая ссылка хуже, чем на одну карточку меньше.

Книги проверяются тем же способом: ASIN книги совпадает с её ISBN-10.

Пока хоть одна позиция помечена `unverified`, это не блокирует деплой:
ссылка на поиск рабочая сама по себе, только без прямого попадания на
карточку товара.
