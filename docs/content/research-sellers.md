# Ресерч: вопросы практиков и продавцов торцевых досок

Дата: 13 августа 2026. Источник: Brave-выдача по Reddit-тредам, LumberJocks, SawmillCreek, WoodworkingTalk, FineWoodworking, Etsy Community.

Собрал материал. Reddit напрямую недоступен (403 и для WebFetch, и для WebSearch), профильные форумы отдают 403, поэтому основа - выдача Brave по reddit-тредам: заголовки постов плюс сниппеты топ-комментариев. Это ровно то, что нужно: заголовок треда и есть реальная формулировка вопроса. Плюс LumberJocks, SawmillCreek, WoodworkingTalk, FineWoodworking, Etsy Community.

## Главное, что видно по выдаче

Боль номер один не «как сделать доску», а «как не работать себе в убыток». Тред за тредом одна и та же сцена: человек показывает доску, спрашивает цену, и в комментариях его бьют по рукам за $60 за торцевую. Постоянно всплывают конкретные цифры: 30% отходов на торцевых досках, Etsy забирает 20%+ с учётом shipping, доставка $15-35 за доску, 150 тысяч листингов по запросу «cutting board».

Второе: **прямое подтверждение product-market fit**. Нашёлся свежий тред r/Cuttingboards «I'm making a website for designing cutting board patterns and I'm curious if anyone would want to use it?» с ответом в духе «иногда просто считаю, какой толщины делать доску, чтобы получить нужную длину, я плохо планирую, обычно получается что получается». Есть старый cbdesigner, которого ругают за поддержку только полосатых узоров (chevron и basket weave не умеет). Есть BeauBilt End Grain Cutting Board Calculator, Hammock Dave Cutting Board Calculator (уже с оценкой стоимости по board-foot), и тред r/BeginnerWoodWorking «End grain cutting board equations for precise dimensions» - человек вывел формулы с учётом kerf вручную, и это собрало отклик. То есть спрос на калькулятор есть, а связки «узор -> распил -> себестоимость -> цена» не делает никто.

## Выводы для продукта

Три темы дают максимальный органический вход для Endgrain Studio, и это ровно то, где сейчас пусто:

**Себестоимость и цена.** Самый горячий кластер вопросов и одновременно самая слабая часть чужих инструментов. Hammock Dave считает материал по board foot, но не считает отходы по конкретному узору, не считает kerf, не считает комиссию площадки и доставку. Связка «нарисовал узор -> увидел настоящую себестоимость -> получил цену» это готовый контент-мост от любого поста про ценообразование в продукт.

**Сложные узоры.** Прямая цитата из выдачи: cbdesigner не умеет chevron и basket weave. При этом именно сложные узоры это единственный способ уйти из ценовой войны с $35-досками. Схемы 3D, chevron и brick с корректной проверкой направления волокна закрывают и техническую боль (трещины по «раствору» в brick), и коммерческую.

**Sale-prep карточка.** Слепое пятно у всех: люди спрашивают отдельно про фото, отдельно про описание, отдельно про гарантию и уход, отдельно про вес для доставки. Всё это выводится из одного проекта автоматически. Ни один конкурент этого не делает, потому что все они инструменты для мастерской, а не для продажи.

Отдельно стоит отметить: в r/Cuttingboards буквально сейчас висит тред человека, который делает сайт для проектирования узоров и спрашивает, нужен ли он кому-то. Это и валидация спроса, и сигнал, что окно открыто ненадолго.
